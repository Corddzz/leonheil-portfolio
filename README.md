A modern, responsive portfolio website built with React, Vite, and Tailwind CSS. This project showcases my work, skills, and professional journey as a Fullstack Developer.

## ✨ Features

- ⚡ **Lightning Fast** – Built with Vite for instant development and optimal performance
- 🎨 **Modern UI** – Tailwind CSS for clean, responsive, and customizable styling
- 📱 **Fully Responsive** – Optimized for all devices from mobile to desktop
- 🧩 **Component-Based** – React components for maintainable and scalable code
- 🔥 **Hot Module Replacement** – Instant feedback during development

## 🛠️ Tech Stack

### Frontend
- **React 18** – Component-based UI library
- **Vite** – Next-generation build tool
- **Tailwind CSS** – Utility-first CSS framework
- **ESLint** – Code quality and consistency
